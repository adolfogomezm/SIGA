# SIGA

Sistema web para la gestión, envío y revisión por pares de artículos académicos y científicos.

## Características Principales

- **Control de Acceso Basado en Roles (RBAC):** Middleware para validación y protección de rutas para roles de autor, revisor y administrador.
- **Gestión de Sesiones:** Manejo seguro de estado de usuario mediante cookies HTTP-only.
- **Persistencia de Datos:** Consultas tipadas e interacción con base de datos relacional.

## Stack Tecnológico

- **Framework:** Astro (SSR)
- **Lenguaje:** TypeScript
- **Base de Datos & ORM:** MySQL + Drizzle ORM
- **Estilos:** Tailwind CSS
